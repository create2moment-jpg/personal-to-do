# Engineering Level Framework (synthetic example)

## L4 — Software Engineer

Delivers well-scoped features end to end with light guidance. Writes tests and
reviews code within the team.

## L5 — Senior Software Engineer

Leads projects across a team. Breaks down ambiguous problems, mentors others and
improves engineering practices. Evidence: design documents, cross-team reviews.

## L6 — Staff Engineer

Sets technical direction across several teams. Drives architecture decisions with
measurable impact on reliability, cost or velocity. Evidence: adopted proposals,
org-wide standards, mentoring of senior engineers.
