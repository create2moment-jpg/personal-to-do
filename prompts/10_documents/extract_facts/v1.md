Extract facts about the person from the passage below. Document type: {{doc_kind}}.

Allowed "kind" values:
- responsibility — what the person owns or is accountable for
- achievement — a concrete accomplishment or result (keep numbers exactly)
- competency — a skill or capability the text attributes to the person
- strength — positive feedback on how they work
- development_area — something to improve
- goal — a stated objective
- level_expectation — what a role/level requires (for level frameworks)

Rules:
- Only use what the passage explicitly says. Do NOT infer or invent. If nothing applies, output [].
- "quote" MUST be copied character-for-character from the passage (a phrase or sentence).
- "statement" is a short neutral restatement (max 25 words).
- "confidence" is 0.0–1.0: how clearly the passage supports the statement.

Output ONLY a JSON array like:
[{"kind": "achievement", "statement": "...", "quote": "...", "confidence": 0.9}]
