Transcribe the text on this scanned page exactly as printed.

Rules:
- Copy every word, name and number exactly. Do not correct, complete, translate or summarise.
- Keep the reading order. Put headings, list items and table rows on their own lines.
- Write [illegible] for anything you cannot read.
- Output only the page text — no introduction, no comments, no code fences.
